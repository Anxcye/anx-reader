# AI 主动阅读闭环

## Feature Status

- Status: Phase 1 implemented; Phase 2 core implemented; Phase 3 implemented
- Priority: P1
- Target release: Unscheduled
- Initial format scope: EPUB
- Product basis: 《如何阅读一本书》中的检视阅读、主动提问、分析阅读和自我测验方法

## Summary

将现有 AI 阅读工作台从以对话和单次文本分析为主的工具，扩展为贯穿读前、读中和读后的主动阅读教练。第一阶段落地四项能力：检视阅读向导、四个主动问题、章节自测和难点暂存箱。

工作台增加“阅读教练 / 对话”一级切换，历史会话、专家和来源入口保持不变。所有 AI 请求都由用户确认触发，默认采用“用户先回答、AI 再提示和校正”的顺序，不增加更多显性的 Agent 按钮。

## Low-Input Interaction Principle

主动阅读闭环采用“选择优先、输入可选”的交互原则，适配平板、墨水屏、外接键盘缺失和触控响应较慢的设备。

- 完成核心流程不要求键盘输入。单选、多选、判断、排序和“一键采用”均视为有效的用户作答。
- 自由文本统一收进“补充想法（可选）”，默认折叠，不自动弹出软键盘。
- AI 先根据书籍与当前章节生成 3-5 个短选项，用户必须选择或明确“暂不确定”；AI 不替用户自动作答。
- 每个问题提供“都不符合 / 暂不确定 / 跳过”出口，避免为了继续流程被迫选择错误答案。
- 默认选项不预先勾选，防止用户一路点击“下一步”产生虚假的阅读成果。
- 选项尽量控制在单屏内：单选不超过 5 项，多选不超过 6 项，文字每项不超过两行。
- E-INK 不使用拖拽排序、滑动手势或动画反馈；排序改为逐对选择或“上移 / 下移”按钮。
- 所有选择结果可在结果页一键修订；切页、关闭工作台和进入历史不会丢失当前选择。

### Input Budget

原方案的最低键盘输入量为：检视阅读 1 次长输入、四个主动问题 4 次长输入、每章自测 3 次长输入，另有阅读目标和难点备注等可选输入。一本 10 章的书至少需要 35 次文本回答。

调整后核心闭环的最低键盘输入量为 0：

| 环节 | 原方案 | 调整后 |
| --- | --- | --- |
| 检视阅读 | 必填“本书在谈什么” | 从 AI 生成的 3 个主题判断中单选，或选择“我还不确定” |
| 阅读目标 | 自由输入 | 目标卡片单选，可选补充文字 |
| 四个主动问题 | 4 个必填长答案 | 单选、多选、判断和优先级选择；文字补充可选 |
| 章节自测 | 每章 3 个开放题 | 3 个选择式互动题；仅“用自己的话回答”需要可选输入 |
| 难点暂存 | 可填写备注 | 一键暂存并选择难点类型；备注可选 |

## Product Behavior

### 检视阅读向导

- EPUB 目录加载完成且本书没有检视记录时，显示“开始检视 / 稍后 / 不再提醒”的本地提示，不自动调用模型。
- 开始前不要求键盘输入。AI 根据书名、简介和目录生成 3 个“本书可能在谈什么”的短判断，用户单选一个，也可选择“我还不确定”。
- 阅读目标使用单选卡：“了解全貌 / 学习知识 / 解决问题 / 批判分析 / 休闲阅读”；选择“解决问题”后提供常见问题建议，仍允许跳过。
- 用户可展开“补充我的判断（可选）”输入文字；默认收起且不自动唤起键盘。
- 输入只包含书籍元数据、完整目录和最多 6 个代表章节，不上传整本书。
- 章节样本包含开头 2000 字和结尾 1000 字；样本覆盖前置内容、前两个正文节点、均匀分布的中间节点和最后正文节点，并按 href 去重。
- 输出包含书籍类型、核心问题、结构概览、关键章节、建议阅读层次、阅读计划、不确定项和可定位的章节引用。阅读计划提供“采用 / 更轻量 / 更深入”三个按钮，不要求编辑计划。
- 报告按书缓存。手动重新生成时保留用户原有回答，并记录模型、供应商、提示版本和生成时间。

### 四个主动问题

每本书固定保存以下四个问题：

1. 整体来说，这本书到底在谈些什么？
2. 作者细部说了什么，怎么说的？
3. 这本书说得有道理吗，是全部还是部分有道理？
4. 这本书跟我有什么关系？

- 每个问题先由 AI 基于本书生成选择卡，再允许用户选择“用自己的话补充”。选择本地自动保存，并保留修订历史。
- 未选择任何选项且没有文字补充时不能请求 AI 评估；“暂不确定”是有效回答，AI 应提供提示而不是评分。
- AI 提供逐级提示、优点、遗漏、追问和原文证据，不覆盖用户答案，也不把模型输出伪装成标准答案。
- 原文证据必须关联章节 href；点击后返回对应章节。
- “说得有道理吗”允许复用现有内部专家和事实核查能力，但默认不联网。

四个问题采用以下低输入题型：

1. “整体谈什么”：从 3-5 个核心主题中单选，随后从 3-5 个核心问题中再单选。
2. “细部怎么说”：多选作者采用的主要结构或论证方式，例如“定义概念 / 讲故事或案例 / 因果推理 / 数据证据 / 反驳其他观点”。
3. “是否有道理”：先单选“基本同意 / 部分同意 / 暂不认同 / 证据不足 / 暂不确定”，再可多选原因“证据充分 / 推理连贯 / 适用范围有限 / 缺少反例 / 数据可能过时”。
4. “跟我有什么关系”：多选“改变认识 / 可以实践 / 帮助决策 / 引发反思 / 暂时无关”，选择可实践时由 AI 给出 3 个行动建议供用户单选。

每题底部固定提供“查看原文依据”“给我一个提示”“补充想法（可选）”，不把文字输入作为主按钮。

### 章节自测

- 阅读器在内存中跟踪每章达到过的最高页码比例。
- 当上一章达到 80% 且切换到下一章时，显示非阻塞提醒；目录跳转、重复 relocation 和未知总页数不应误触发。
- 用户确认后才读取上一章并生成 3 道选择式互动题，覆盖内容复述、关键主张或结构、联系或批评。
- 默认题型为“选出本章主旨”“选出作者的论证路径”“判断哪项最符合本章观点”；可混合单选、多选和判断，不依赖文字输入。
- 每题包含 3-5 个短选项和“暂不确定”。错误选项必须来自本章常见误解，不使用明显凑数的干扰项。
- 用户提交选择后才能查看提示和评估；每题可选“用自己的话回答”，但不影响完成自测。
- 反馈采用“待复习 / 基本掌握 / 理解扎实”三级掌握度，不使用百分制。
- 反馈页只展示一条最重要的遗漏和两个动作：“回到原文 / 下一题”，避免要求用户继续输入追问。
- 重新生成会创建新的自测尝试，历史答案和反馈保持可查看。
- 选择“稍后”或生成失败的章节继续显示在阅读教练总览中，不反复阻断阅读。

### 难点暂存箱

- 长按选区菜单的“更多”和 AI 选区动作卡都增加“暂存难点”。
- 暂存操作只写本地数据，不调用 AI，也不混入普通划线笔记。
- 保存书籍、章节、CFI、选中文本、相邻上下文、难点类型、可选用户备注和处理状态；相同书籍、CFI 和文本应去重。
- 点击“暂存难点”后直接保存，不先打开表单；保存完成后用轻量动作条提供类型选择：“概念不懂 / 论证没跟上 / 背景缺失 / 有疑问 / 稍后再想”。
- 未解决难点在正文中显示高对比虚线下划线，兼容横排、竖排和 E-INK。
- 点击标记打开阅读教练中的难点详情，可定位原文，并提供“简单解释 / 举个例子 / 联系上下文 / 查背景 / 标记解决”动作按钮；添加备注放在二级入口。
- 标记解决后移除正文下划线，但保留历史记录和 AI 处理结果。
- 切章提醒合并显示待处理难点数量和章节自测入口，避免连续弹窗。

## Architecture And Data

数据库版本从 11 升级到 12，新增以下数据表：

- `tb_reading_guides`：按 `book_id` 保存检视状态、读前判断、阅读目标、报告、四个问题、答案修订记录和生成元数据。
- `tb_reading_quizzes`：按书籍和章节保存提醒状态、题目、用户答案、AI 反馈、掌握度和历史尝试。
- `tb_reading_difficulties`：保存难点位置、上下文、备注、状态、解决结果和时间字段。

新增主要接口：

- `InspectionReadingGuide`
- `ActiveReadingQuestion` / `AnswerRevision`
- `ChapterQuiz` / `QuizAttempt` / `ReadingMasteryLevel`
- `ReadingDifficulty` / `ReadingDifficultyStatus`
- `ReadingCoachRepository` 和按 `bookId` 隔离的 Riverpod provider
- `ChapterContentHandlers.fetchChapterSampleByHref(...)`

foliate-js 批注接口增加独立 `annotationKey`，将批注身份与 CFI 分离，使难点标记可以和相同 CFI 的普通划线共存。旧批注不提供 `annotationKey` 时继续使用原有 CFI 行为。

AI 结构化返回必须经过 schema 校验。无法解析时使用同一请求纠正一次；仍失败则保留原数据、记录可诊断日志并展示可重试错误。调用复用现有通用 AI 模型、备用供应商和内部多 Agent 调度。

所有数据进入现有 SQLite 数据库，因此自动使用现有 WebDAV 数据库同步。软删除书籍时保留阅读成果，永久删除时随书清理。

## UI And Accessibility

- 工作台仍默认打开现有对话页；首次检视提示或用户点击“阅读教练”后进入教练页。
- 阅读教练总览依次展示检视报告、四个问题进度、待完成章节自测和未解决难点。
- 宽屏继续使用可调宽右侧分栏，手机继续使用全屏工作台。
- 隐藏工作台、查看历史或切换对话时，不销毁草稿、滚动位置或阅读教练状态。
- E-INK 使用纯黑边框、虚线、字重和静态状态表达，不依赖透明色和动画。
- 选择卡使用整行点击区域，最小高度 48dp；选中状态同时使用图标、字重和实线边框，不只依赖颜色。
- 手机和平板的主要动作固定在底部：“稍后 / 暂不确定 / 确认”；墨水屏不使用横向滑动选项、长按二级动作或拖拽排序。
- 软件键盘仅在用户主动点击“补充想法”后出现；返回键先收起键盘，再返回上一级。
- 新文案提供英文和简体中文，其他语言使用英文回退。

## Failure And Privacy Rules

- 未配置 AI 时，四个主动问题和难点箱仍可离线使用；需要生成的功能展示 AI 配置入口。
- 检视、自测和普通反馈默认只使用本书内容，不自动联网。
- 章节正文抽样必须有字符上限，不把整本书作为单次模型上下文。
- AI 失败不得覆盖用户答案、已有报告、自测记录或难点状态。
- 模型推断和原文内容必须在界面中明确区分，引用无法定位时不得伪造位置。

## Acceptance Tests

- 数据库从版本 11 升级后新表、索引和默认值正确，旧书籍、笔记及 AI 会话不受影响。
- 检视抽样覆盖前、中、后章节和章节头尾，并严格执行数量与字符上限。
- 首次提示、稍后、不再提醒、缓存复用和手动重新生成状态正确。
- 四个问题在空答案时不能调用 AI，答案修订和反馈可跨重启恢复。
- 不打开软键盘即可完成检视阅读、四个主动问题、章节自测和难点分类的完整闭环。
- 所有 AI 生成选择题均包含“暂不确定”或等价出口，选项数量、行数和触控区域符合低输入限制。
- E-INK 下不依赖拖拽、横滑和动画完成任何核心操作，连续选择时页面不发生非必要整屏刷新。
- 章节达到 80% 后切章只提醒一次，目录跳转和未知页数不会误触发。
- 自测题缓存、历史尝试、三级掌握度、脏返回纠正和失败重试正确。
- 难点去重、原文定位、普通批注共存、点击打开和解决后移除正确。
- Widget 测试覆盖阅读教练/对话切换、移动端全屏、宽屏分栏和 E-INK。
- foliate-js 重新构建后通过 Chrome 83 兼容验证，并完成 Flutter 单元测试和 `flutter analyze`。
- macOS 与 Android 真机完成 EPUB 检视、切章提醒、自测和难点处理验收。

## Out Of Scope

- PDF、TXT 或其他非 EPUB 格式的章节闭环。
- 自动上传整本书、自动联网或后台自动调用模型。
- 用户自定义阅读方法和可视化 Agent 编排。
- 跨书主题阅读、作者术语表、命题图和长期间隔复习；这些作为后续阶段单独规划。

## Phase 2 Core

第二阶段第一批实现将单章闭环扩展到整本书理解和长期记忆，同时继续保持零强制输入：

- 用户主动触发 AI 个性化检视向导。仅发送目录和最多 6 个代表章节的头尾抽样，生成本书主题选项、结构、关键章节、阅读计划和个性化四问选项。
- 关键章节可直接定位原文，阅读计划通过“轻量 / 标准 / 深入”单选保存，不要求编辑文字。
- 新增“今日复习”，按章节掌握度使用 1 天、3 天、7 天间隔重新安排选择式自测。
- 新增“整本书成果”，只汇总用户主动问题答案、自测掌握度和难点状态，生成关键观点、可选行动和待核查问题，不上传整本书。
- AI 结构化返回严格校验并自动纠正一次；失败不覆盖已有向导、用户答案或阅读成果。

第二阶段后续批次保留跨书主题阅读、概念关系图、难点聚类和长期复习历史，不在本批实现范围内。

## Phase 3: Knowledge Cards And Adaptive Review

第三阶段在当前书内形成“来源整理 → 主题确认 → 卡片确认 → 间隔复习 → 历史反馈”闭环：

- 用户主动点击“整理新内容”后，仅读取当前书未参与既有主题的难点、带文字划线和读者笔记；单批最多 80 条，每条最多 240 字，不后台扫描、不读取整本书。
- AI 返回 2-8 个建议主题，用户逐项保留或忽略。保留主题可主动生成 3-8 张建议卡片，卡片也必须逐张确认后才进入复习。
- 知识卡使用五级固定间隔 1、3、7、14、30 天。“困难”回退一级，“记得”前进一级，“掌握”前进两级，第 5 级继续按 30 天复习。
- 复习严格采用“问题 → 查看答案 → 困难 / 记得 / 掌握 → 下一张”的按钮流程，未揭示答案不能评级，评级后不自动切卡。
- 每次评级记录前后阶段和时间，历史按日期分组并默认展开最新日期，支持撤销最近一次评级。
- 来源保留章节、CFI 和文本快照。原难点或笔记已删除时禁用定位，仅显示快照和“原位置不可用”。
- 数据库版本升级为 v13，知识来源、主题、主题来源关系、卡片、卡片来源关系和复习记录使用六张独立表；软删除书籍保留数据，永久清理接口按书事务删除全部记忆数据。
- 核心流程不要求键盘、拖拽、横滑或翻转动画，适用于手机、平板和 E-INK。AI 只在用户点击整理或生成卡片时调用，默认不联网、不调用多 Agent。

第三阶段明确不包含概念关系图、跨书聚类、全书架复习总入口和阅读项目。
